# Code of Conduct

## Our Standard

We are committed to a respectful, inclusive, and constructive collaboration environment.

Expected behavior:
- Be respectful in communication.
- Focus on technical arguments, not personal attacks.
- Give and receive feedback professionally.
- Help keep documentation and discussion clear for all contributors.

Unacceptable behavior:
- Harassment, insults, or discrimination.
- Trolling or intentionally disruptive behavior.
- Publishing private information without consent.

## Enforcement

Maintainers may edit, remove, or reject contributions and interactions that violate this code of conduct.

For concerns, open a GitHub issue for non-sensitive matters, or use [GitHub Security Advisories](../../security/advisories/new) for reports that should not be public. If neither is appropriate, contact a maintainer directly through the contact information on their GitHub profile.
