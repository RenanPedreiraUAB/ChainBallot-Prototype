# Security Policy

## Supported Scope

This repository is a research prototype and reference implementation. It is not production-ready by default.

Security reports are still welcome and will be triaged.

## Reporting a Vulnerability

Please do not open public issues for sensitive security findings.

Report privately using [GitHub Security Advisories](../../security/advisories/new) for this repository, which creates a private discussion visible only to you and the maintainers. Include:
- Affected component(s)
- Reproduction steps
- Impact assessment
- Suggested mitigation (if available)

If you cannot use GitHub Security Advisories, open a minimal public issue without exploit details and request a private follow-up channel.

## Handling Policy

1. Report received and acknowledged.
2. Severity and impact triaged.
3. Fix prepared and validated.
4. Fix merged and disclosure coordinated with the reporter.
